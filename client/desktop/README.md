# Anchor Chat desktop client

Anchor Chat by STC Worldwide. This Electron shell opens the chat deployment;
Anchor Desktop is the separate desktop product in `stcdesk`. Existing profiles,
server lists and the application ID stay compatible. See
[the branding contract](../../docs/branding.md).

## Usage

### Install dependency

```bash
yarn
```

### dev

```bash
yarn dev
```

### package

```bash
yarn package
```
